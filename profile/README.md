# Reinyard

**A controlled place for agents to work.**

Reinyard is a platform for building, versioning and running agents and
automations. Pipelines live in Git and run in isolated sandboxes, and every run
is recorded, so you always know what happened and which version did it.

It is self-hosted, with a managed cloud coming soon.
